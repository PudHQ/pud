# Rockbuster™

I have this idea, that the best way to demo Pud is to make something interactive, intriguing and kinda funny. When I was researching formal verification, most LLMs decided the _only_ way to talk to me about it was in the context of [\[non-\]negative balances.](/notes/factoids/llm-obsession-with-balances/)

Yeah, maybe that is a good example, but surely it's not the _only_ example? (Of course it isn't...) I think there must be a lot of blockchain contract-related text in the training data, and that's the definition that LLMs over-optimise for when asked to explain formal verification in a software engineering context.

Anyway.

I started thinking about what a fun, toy example use case would be -- which still allowed us to talk about "balances" as a strong example to run formal verification on, and the thought of doing something retro popped into my head; my next thought was -- we could make a Blockbuster example, i.e. video rental.

Then my mind went to riff off of the name Blockbuster (because obviously I'm not going to call my example repo Blockbuster), and I came up with Rockbuster[^1]... A virtual rock-rental shop. For [grug-brained developers.](https://grugbrain.dev/)

So that's what I want to make!

Stay tuned...?

[^1]: I also can't decide if it would be more funny to call it Rocqbuster or not... But I don't want the pun to get too multilayered.
