# Poster layout fieldnotes

Set the line you want read first in the largest type and break it at phrase boundaries.
Borrow one compositional move from a poster reference, such as Tanaka’s broad color shapes, and let the brand supply the illustration. [Tanaka at Cooper Hewitt](https://www.cooperhewitt.org/2015/12/05/do-i-look-simple/)
Fit the longest line with the production font loaded and check that neighboring strokes stay separate before tightening the tracking.
Measure the outer gutters on phone and desktop, check for horizontal overflow, and make sure a slanted band clears the first and last letters inside it.
